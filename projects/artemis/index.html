Install the app

artemis.apk Android client

  1. Download artemis.apk on an Android phone (Android 7 or newer) and open it.
  2. Allow your browser to install unknown apps when Android asks.
  3. In the app's server settings, enter the server URL, your callsign and your password.

Install the server

artemis-server-amd64.tar.gz Server image, x86-64

artemis-server-arm64.tar.gz Server image, ARM64

docker-compose.yml Server stack

  1. Needs Docker with Compose. Download the image for your machine and docker-compose.yml into one directory, then load the image: 
    docker load -i artemis-server-amd64.tar.gz
  2. Create the settings file next to docker-compose.yml: 
    cat > .env <<EOF
POSTGRES_PASSWORD=$(openssl rand -hex 16)
JWT_SIGNING_KEY=$(openssl rand -base64 48)
ARTEMIS_DATA_DIR=/opt/artemis/data
EOF
  3. Start it: 
    docker compose up -d
  4. Create the first account, an admin: 
    docker compose exec server dotnet Artemis.Server.dll create-user <callsign> <password> --admin
  5. Put an HTTPS reverse proxy in front of http://127.0.0.1:5000, passing websockets through on /api/sync. The console is at its root, and the app connects to the same address.
